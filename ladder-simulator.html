Ladder Logic Simulator

This is a self-directed learning project, a browser-based simulator that models how a real PLC evaluates ladder logic, translating the fault-interlock state machine from my Raspberry Pi Pico trainer into Allen-Bradley/RSLogix notation (XIC, XIO, OTE), the North American industry standard for the equipment I'd be working with in a maintenance role.

What this is: a learning tool I built to understand ladder logic concepts, not a certified, IEC 61131-3-compliant, or production PLC programming environment.

How each rung maps to the Pico trainer

Rung 1: Fault latch

The Jam contact sets the Fault coil, and a seal-in contact (Fault, in parallel with Jam) keeps it energized on its own even after Jam clears, exactly like the Pico's fault-interlock logic stayed latched in the Fault state until told otherwise. Only Reset breaks the seal. This is the same behavior as the Pico's state = "Fault" holding until the reset switch was read.

Show the code if jam or fault: fault = True and not reset

Rung 2: Start/Stop seal-in with fault interlock

This is the classic motor-starter circuit. Start energizes Run, a seal-in contact (Run) keeps it energized after Start is released, and Stop breaks the seal. The Fault contact in series cuts the whole rung the moment Fault is set, the same lockout the Pico enforced by disabling Start and Stop whenever state == "Fault".

Show the code if (start or run) and not stop and not fault: run = True else: run = False

Rung 3: Motor output

A direct output. Run energizes the Motor coil, mirroring the Pico's status LEDs turning on when it entered the Running state.

Show the code motor = run

What's simplified here

The Pico trainer requires holding the Jam switch for 2 seconds before it counts as a fault (debounce), so a quick bump doesn't trip it. A real PLC would do that with a timer instruction (TON). I left that out here on purpose, to keep the diagram focused on scan-cycle behavior and NO/NC contact logic, the two core concepts this project is built to demonstrate.
